# ChatGPT orchestration guide

This repository is an Instagram content system, not an autonomous posting bot. ChatGPT should draft, analyze, research, and create assets; the user approves and publishes unless an official Meta integration is explicitly connected later.

## State to read first
1. instagram/PROFILE.md
2. instagram/VOICE.md
3. instagram/CONTENT_STRATEGY.md
4. instagram/PERFORMANCE.md when performance is relevant
5. instagram/SWIPE.md when trend/formula research is relevant

## Default pipeline
IDEA -> research when needed -> 3 hook candidates -> hookscore.py -> script -> beats.py -> ig-human -> shooting plan -> caption / carousel assets -> user approval -> manual publish -> metrics -> ig-audit -> update strategy/experiments.

## Current information
Instagram behavior, limits, APIs, product features, ranking guidance, and policy can change. Verify current platform claims before treating them as PLATFORM evidence.

## User-specific learning
Generic advice is a prior. The user's own account data should progressively override generic defaults when the sample is meaningful. Keep contradictory evidence instead of smoothing it away.
