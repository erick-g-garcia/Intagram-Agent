# Evidence model

Use four labels:

- PLATFORM: current official Meta/Instagram documentation or product behavior verified at time of use.
- ACCOUNT DATA: metrics or controlled observations from this Instagram account.
- OBSERVATIONAL: patterns in an external sample; always state n and collection method.
- HEURISTIC: a practical rule of thumb, useful for testing but not a platform fact.

If two sources conflict, prefer current PLATFORM facts for product constraints and ACCOUNT DATA for what works on this account.
